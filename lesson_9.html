Генератор паролей

средненовоеавтопроверка

Напиши функцию make_password(length), которая возвращает случайный пароль заданной длины из латинских букв и цифр.

Показать ответ (сначала попробуй сам!)
import random
import string

symbols = string.ascii_letters + string.digits


def make_password(length):
    password = ''
    for _ in range(length):
        password += random.choice(symbols)
    return password

Дневник в файле

средненовоеавтопроверка

Запиши в файл diary.txt три строки: Учил Python, Решил 5 задач, Играл в футбол. Потом прочитай файл и выведи строки с номерами.

Ожидаемый вывод

1: Учил Python
2: Решил 5 задач
3: Играл в футбол
Подсказка

Запись: with open('diary.txt', 'w') as f: f.write('текст\n'). Чтение по строкам: for line in open('diary.txt'):. Лишний перенос строки убирает .strip().

Показать ответ (сначала попробуй сам!)
notes = ['Учил Python', 'Решил 5 задач', 'Играл в футбол']

with open('diary.txt', 'w', encoding='utf-8') as f:
    for note in notes:
        f.write(note + '\n')

with open('diary.txt', encoding='utf-8') as f:
    for number, line in enumerate(f, start=1):
        print(f'{number}: {line.strip()}')
