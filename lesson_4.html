Високосный год

средненовоеавтопроверка

Пользователь вводит год. Выведи «високосный» или «обычный».

Год високосный, если он делится на 4, но не делится на 100. Исключение: годы, которые делятся на 400, — тоже високосные.

Пример работы

Введи год: 2024
високосный
Подсказка

Пригодятся операторы %, and, or.

Показать ответ (сначала попробуй сам!)
year = int(input('Введи год: '))

if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print('високосный')
else:
    print('обычный')

Светофор

легконовоеавтопроверка

Пользователь вводит цвет светофора. Программа подсказывает, что делать:

  • красный → Стой
  • жёлтый → Жди
  • зелёный → Иди
  • любой другой цвет → Такого цвета нет
Показать ответ (сначала попробуй сам!)
color = input('Какой свет горит? ').lower()

if color == 'красный':
    print('Стой')
elif color == 'жёлтый' or color == 'желтый':
    print('Жди')
elif color == 'зелёный' or color == 'зеленый':
    print('Иди')
else:
    print('Такого цвета нет')

Оценка за контрольную

легконовоеавтопроверка

Пользователь вводит количество баллов от 0 до 100. Выведи оценку:

  • 90 и больше — 5
  • от 75 до 89 — 4
  • от 50 до 74 — 3
  • меньше 50 — 2

Пример работы

Сколько баллов? 80
Оценка: 4
Показать ответ (сначала попробуй сам!)
points = int(input('Сколько баллов? '))

if points >= 90:
    print('Оценка: 5')
elif points >= 75:
    print('Оценка: 4')
elif points >= 50:
    print('Оценка: 3')
else:
    print('Оценка: 2')

Самое большое из трёх

средненовоеавтопроверка

Пользователь вводит три числа. Выведи самое большое из них, не используя функцию max().

Пример работы

Первое: 3
Второе: 9
Третье: 4
Самое большое: 9
Показать ответ (сначала попробуй сам!)
a = int(input('Первое: '))
b = int(input('Второе: '))
c = int(input('Третье: '))

biggest = a
if b > biggest:
    biggest = b
if c > biggest:
    biggest = c
print('Самое большое:', biggest)
