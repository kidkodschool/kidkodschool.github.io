🧠Разминка

Шпаргалка: // — целочисленное деление, % — остаток от деления, ** — степень. Если в выражении есть хотя бы одно число float (с точкой) — результат тоже будет float.

Определи тип данных у выражений

легко

Для каждого выражения сначала подумай, какой получится тип — int или float. Потом проверь себя в редакторе с помощью type().

  • 2 + 2 * 3 // 0.1
  • 0.1 + 2 / 3 // 0.1 % 2
  • 1 * float(1) - 0
  • 10 * int(1) - 0 * 0.0
Показать ответ (сначала попробуй сам!)
# Все четыре выражения дают float:
print(type(2 + 2 * 3 // 0.1))        # <class 'float'>  (есть 0.1)
print(type(0.1 + 2 / 3 // 0.1 % 2))  # <class 'float'>  (деление / всегда даёт float)
print(type(1 * float(1) - 0))        # <class 'float'>  (float(1) == 1.0)
print(type(10 * int(1) - 0 * 0.0))   # <class 'float'>  (0 * 0.0 == 0.0)

Сколько секунд в сутках?

легконовоеавтопроверка

Посчитай с помощью Python, сколько секунд в сутках, в неделе и в году (365 дней). Выведи три числа — каждое на своей строке.

Показать ответ (сначала попробуй сам!)
seconds_in_minute = 60
minutes_in_hour = 60
hours_in_day = 24

day = seconds_in_minute * minutes_in_hour * hours_in_day
print(day)
print(day * 7)
print(day * 365)

Конфеты поровну

легконовоеавтопроверка

У Пети 47 конфет. Он хочет раздать их поровну 5 друзьям. Сколько конфет получит каждый и сколько останется Пете?

Используй операторы // и %.

Пример вывода

Каждый получит: 9
Останется: 2
Показать ответ (сначала попробуй сам!)
candies = 47
friends = 5
print('Каждый получит:', candies // friends)
print('Останется:', candies % friends)
4

Прямоугольник

легконовоеавтопроверка

Стороны прямоугольника равны a = 7 и b = 4. Выведи его площадь и периметр.

Пример вывода

Площадь: 28
Периметр: 22
Показать ответ (сначала попробуй сам!)
a = 7
b = 4
print('Площадь:', a * b)
print('Периметр:', 2 * (a + b))
5

Средняя оценка

средненовоеавтопроверка

За неделю ты получил оценки 5, 4, 5. Найди среднюю оценку и выведи её, округлив до двух знаков после точки функцией round(число, 2).

Пример вывода

Средняя оценка: 4.67
Показать ответ (сначала попробуй сам!)
a = 5
b = 4
c = 5
average = (a + b + c) / 3
print('Средняя оценка:', round(average, 2))
6
