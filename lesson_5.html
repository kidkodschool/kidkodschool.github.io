Обратный отсчёт

легконовоеавтопроверка

Пользователь вводит число n. С помощью цикла while выведи числа от n до 1, а в конце — «Старт! 🚀».

Пример работы

С какого числа? 3
3
2
1
Старт! 🚀
Показать ответ (сначала попробуй сам!)
n = int(input('С какого числа? '))
while n > 0:
    print(n)
    n -= 1
print('Старт! 🚀')

Сумма цифр

средненовоеавтопроверка

Пользователь вводит целое число. Посчитай сумму его цифр.

Пример работы

Число: 12345
Сумма цифр: 15
Подсказка

Можно перебрать строку символ за символом: for digit in text:, а можно в цикле брать остаток n % 10 и делить n //= 10.

Показать ответ (сначала попробуй сам!)
text = input('Число: ')
total = 0
for digit in text:
    total += int(digit)
print('Сумма цифр:', total)

FizzBuzz

средненовоеавтопроверка

Классическая задача программистов! Выведи числа от 1 до 30, но:

  • вместо чисел, которые делятся на 3, пиши Fizz;
  • вместо тех, что делятся на 5, — Buzz;
  • а если делится и на 3, и на 5 — FizzBuzz.

Начало вывода

1
2
Fizz
4
Buzz
Fizz
7
...
Показать ответ (сначала попробуй сам!)
for i in range(1, 31):
    if i % 15 == 0:
        print('FizzBuzz')
    elif i % 3 == 0:
        print('Fizz')
    elif i % 5 == 0:
        print('Buzz')
    else:
        print(i)

Игра «Угадай число»

средненовое

Компьютер загадывает случайное число от 1 до 50 (from random import randint). Игрок угадывает, а программа подсказывает «больше» или «меньше». Когда число угадано — выведи количество попыток.

Подсказка

Бесконечный цикл while True: можно прервать командой break.

Показать ответ (сначала попробуй сам!)
from random import randint

secret = randint(1, 50)
print('Я загадал число от 1 до 50. Угадаешь?')
tries = 0

while True:
    guess = int(input('Твой вариант: '))
    tries += 1
    if guess < secret:
        print('Моё число больше ⬆')
    elif guess > secret:
        print('Моё число меньше ⬇')
    else:
        print(f'Угадал за {tries} попыток! 🎉')
        break
