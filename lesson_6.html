Максимум из трёх

легконовоеавтопроверка

Напиши функцию max_of_three(a, b, c), которая возвращает наибольшее из трёх чисел. Встроенную max() не используй!

Показать ответ (сначала попробуй сам!)
def max_of_three(a, b, c):
    result = a
    if b > result:
        result = b
    if c > result:
        result = c
    return result

Считаем гласные

средненовоеавтопроверка

Напиши функцию count_vowels(text), которая возвращает количество гласных букв в строке. Гласные: аеёиоуыэюя и aeiou. Большие буквы тоже считаются.

Показать ответ (сначала попробуй сам!)
def count_vowels(text):
    vowels = 'аеёиоуыэюяaeiou'
    count = 0
    for letter in text.lower():
        if letter in vowels:
            count += 1
    return count

Приветствие на разных языках

средненовоеавтопроверка

Напиши функцию greet(name, lang='ru') с аргументом по умолчанию. Она возвращает строку:

  • greet('Аня') → 'Привет, Аня!'
  • greet('Аня', 'en') → 'Hello, Аня!'
  • greet('Аня', 'es') → 'Hola, Аня!'
  • для неизвестного языка — как для 'ru'
Показать ответ (сначала попробуй сам!)
def greet(name, lang='ru'):
    if lang == 'en':
        return f'Hello, {name}!'
    if lang == 'es':
        return f'Hola, {name}!'
    return f'Привет, {name}!'
