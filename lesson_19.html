Шифровка гласных

легкоавтопроверка

Создай функцию encode(), которая заменяет буквы по схеме: a → 1, e → 2, i → 3, o → 4, u → 5. Например, encode("hello") → "h2ll4".

Создай функцию decode(), которая заменяет цифры обратно на буквы: decode("h2ll4") → "hello".

Показать ответ (сначала попробуй сам!)
def encode(st):
    for i, v in enumerate('aeiou', start=1):
        st = st.replace(v, str(i))
    return st


def decode(st):
    for i, v in enumerate('aeiou', start=1):
        st = st.replace(str(i), v)
    return st

Звёздочки для букв

среднеавтопроверка

Функция get_strings(city) получает название города и возвращает строку, показывающую, сколько раз каждая буква встречается в нём (звёздочками). Регистр не важен, пробелы игнорируются, буквы идут в порядке первого появления.

Примеры

"Moscow"  → "m:*,o:**,s:*,c:*,w:*"
"Chicago" → "c:**,h:*,i:*,a:*,g:*,o:*"
Показать ответ (сначала попробуй сам!)
def get_strings(city):
    city = city.lower().replace(' ', '')
    parts = []
    for letter in city:
        item = f'{letter}:' + '*' * city.count(letter)
        if item not in parts:
            parts.append(item)
    return ','.join(parts)

Очки в «Скрабл»

среднеавтопроверка

Напиши функцию scrabble_score(word), которая считает очки за слово в игре Скрабл. Регистр не важен.

Таблица очков

A, E, I, O, U, L, N, R, S, T → 1
D, G → 2
B, C, M, P → 3
F, H, V, W, Y → 4
K → 5
J, X → 8
Q, Z → 10

Пример

"cabbage" → 14  (3 + 1·2 + 3·2 + 2 + 1)
Показать ответ (сначала попробуй сам!)
POINTS = {
    'aeioulnrst': 1, 'dg': 2, 'bcmp': 3, 'fhvwy': 4, 'k': 5, 'jx': 8, 'qz': 10,
}


def scrabble_score(word):
    score = 0
    for letter in word.lower():
        for letters, value in POINTS.items():
            if letter in letters:
                score += value
    return score

Шифр Цезаря

средненовоеавтопроверка

Напиши функцию caesar(text, shift), которая сдвигает каждую маленькую латинскую букву на shift позиций по алфавиту (после z снова идёт a). Остальные символы не меняются.

Примеры

caesar('abc', 1)        → 'bcd'
caesar('xyz', 3)        → 'abc'
caesar('hello, world', 13) → 'uryyb, jbeyq'
Подсказка

Номер буквы в алфавите: ord(ch) - ord('a'), обратно — chr(номер + ord('a')). Остаток % 26 поможет «закольцевать» алфавит.

Показать ответ (сначала попробуй сам!)
def caesar(text, shift):
    result = ''
    for ch in text:
        if 'a' <= ch <= 'z':
            result += chr((ord(ch) - ord('a') + shift) % 26 + ord('a'))
        else:
            result += ch
    return result

Сортировка пузырьком

средненовоеавтопроверка

Напиши функцию bubble_sort(arr), которая сортирует список по возрастанию без sort() и sorted() и возвращает его. Идея: много раз проходим по списку и меняем местами соседей, стоящих не по порядку.

Показать ответ (сначала попробуй сам!)
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

Бинарный поиск

сложноновоеавтопроверка

Напиши функцию binary_search(arr, x): в отсортированном списке находит индекс числа x или возвращает -1. Каждый шаг смотри на середину и отбрасывай половину списка.

Показать ответ (сначала попробуй сам!)
def binary_search(arr, x):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == x:
            return mid
        if arr[mid] < x:
            left = mid + 1
        else:
            right = mid - 1
    return -1
