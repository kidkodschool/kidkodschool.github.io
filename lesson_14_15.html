Пароль

легкоавтопроверка

Программа спрашивает пароль. Если введён пароль Abra! — она приветствует: Greetings, sir!, иначе прогоняет: Go away, stranger.

Показать ответ (сначала попробуй сам!)
greeting = input("Hello, what is the password? ")

if greeting in ["Abra!"]:
    print("Greetings, sir!")
else:
    print("Go away, stranger.")

Писатели

среднеавтопроверка

Программа должна вывести, в каком году умер каждый писатель, например: Charles Dickens died in 1870.

Показать ответ (сначала попробуй сам!)
authors = {
    "Charles Dickens": "1870",
    "William Thackeray": "1863",
    "Anthony Trollope": "1882",
    "Gerard Manley Hopkins": "1889"
}

for author, date in authors.items():
    print(author + " died in " + date + ".")

Машина времени

среднеавтопроверка

Пользователь вводит год. До 1900 года включительно — прошлое, с 1901 по 2019 — настоящее, дальше — будущее.

Показать ответ (сначала попробуй сам!)
year = int(input("Greetings! What is your year of origin? "))

if year <= 1900:
    print("Woah, that's the past!")
elif year > 1900 and year < 2020:
    print("That's totally the present!")
else:
    print("Far out, that's the future!!")

Знакомство

среднеавтопроверка

Класс Person должен представляться: My name is Olli Green.

Показать ответ (сначала попробуй сам!)
class Person:
    def __init__(self, first_name, last_name):
        self.first = first_name
        self.last = last_name

    def speak(self):
        print("My name is " + self.first + " " + self.last)


me = Person("Olli", "Green")
you = Person("Tommy", "Wiseau")

me.speak()
you.speak()

Средний балл

сложноавтопроверка

Программа спрашивает три оценки за экзамены (по 100-балльной шкале), считает среднее и итоговую оценку.

Показать ответ (сначала попробуй сам!)
exam_one = int(input("Input exam grade one: "))
exam_two = int(input("Input exam grade two: "))
exam_three = int(input("Input exam grade three: "))

grades = [exam_one, exam_two, exam_three]

total = 0
for grade in grades:
    total = total + grade

avg = total / len(grades)

if avg >= 90:
    letter_grade = "5"
elif avg >= 80 and avg < 90:
    letter_grade = "4"
elif avg > 69 and avg < 80:
    letter_grade = "3"
elif avg <= 69 and avg >= 65:
    letter_grade = "2"
else:
    letter_grade = "1"

for grade in grades:
    print("Exam: " + str(grade))

print("Average: " + str(avg))
print("Grade: " + letter_grade)

if letter_grade == "1":
    print("Student is failing.")
else:
    print("Student is passing.")

🛡️Обработка исключений

Конструкция try / except ловит ошибку, чтобы программа не падала: try: — что пробуем сделать, except ZeroDivisionError: — что делать, если случилась такая ошибка.

Безопасное деление

легконовоеавтопроверка

Напиши функцию safe_div(a, b), которая возвращает a / b, а при делении на ноль — None. Используй try / except.

Показать ответ (сначала попробуй сам!)
def safe_div(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None

Упрямый ввод

средненовоеавтопроверка

Напиши функцию ask_number(), которая просит ввести целое число, пока пользователь не введёт его правильно, и возвращает это число. На неправильный ввод — сообщение «Это не число, попробуй ещё раз».

Показать ответ (сначала попробуй сам!)
def ask_number():
    while True:
        try:
            return int(input('Введи число: '))
        except ValueError:
            print('Это не число, попробуй ещё раз')


print('Ты ввёл', ask_number())

Своё исключение

средненовоеавтопроверка

Напиши функцию set_age(age), которая возвращает возраст, если он от 0 до 150, а иначе выбрасывает ошибку ValueError с текстом «Неверный возраст» (raise).

Показать ответ (сначала попробуй сам!)
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError('Неверный возраст')
    return age
