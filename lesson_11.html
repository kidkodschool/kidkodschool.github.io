🪆Рекурсия

Рекурсия — это когда функция вызывает саму себя. Важно не забыть базовый случай — условие, при котором функция перестаёт себя вызывать. Подробнее — на pythontutor.ru.

1

Факториал

легконовоеавтопроверка

Напиши рекурсивную функцию factorial(n). Факториал: 5! = 5 × 4 × 3 × 2 × 1 = 120, а 0! = 1.

Показать ответ (сначала попробуй сам!)
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
2

Обратный отсчёт

легконовоеавтопроверка

Напиши рекурсивную функцию countdown(n), которая печатает числа от n до 1, а затем «Пуск!». Циклы не используй.

Показать ответ (сначала попробуй сам!)
def countdown(n):
    if n == 0:
        print('Пуск!')
        return
    print(n)
    countdown(n - 1)
3

Числа Фибоначчи

средненовоеавтопроверка

Напиши рекурсивную функцию fib(n), которая возвращает n-е число Фибоначчи: 0, 1, 1, 2, 3, 5, 8, 13… (fib(0) = 0, fib(1) = 1, дальше каждое — сумма двух предыдущих).

Показать ответ (сначала попробуй сам!)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)
4

Сумма цифр рекурсией

средненовоеавтопроверка

Напиши рекурсивную функцию sum_digits(n), которая возвращает сумму цифр натурального числа.

Подсказка

Последняя цифра — n % 10, остальные — n // 10.

Показать ответ (сначала попробуй сам!)
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)
5

Степень числа

легконовоеавтопроверка

Напиши рекурсивную функцию power(a, n), которая возводит a в натуральную степень n без оператора **.

Показать ответ (сначала попробуй сам!)
def power(a, n):
    if n == 0:
        return 1
    return a * power(a, n - 1)
