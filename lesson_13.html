Вектор

средненовоеавтопроверка

Создай класс Vector(x, y), который умеет:

  • складываться: Vector(1, 2) + Vector(3, 4) → Vector(4, 6) (__add__);
  • сравниваться: Vector(1, 2) == Vector(1, 2) → True (__eq__);
  • красиво печататься: str(Vector(1, 2)) → '(1, 2)' (__str__).
Показать ответ (сначала попробуй сам!)
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    def __str__(self):
        return f'({self.x}, {self.y})'

Зоопарк

легконовоеавтопроверка

Создай класс Animal(name) с методом speak(), который возвращает '...'. Унаследуй от него классы Cat и Cow и переопредели speak():

  • Cat('Мурка').speak() → 'Мурка: Мяу!'
  • Cow('Зорька').speak() → 'Зорька: Му!'
Показать ответ (сначала попробуй сам!)
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return '...'


class Cat(Animal):
    def speak(self):
        return f'{self.name}: Мяу!'


class Cow(Animal):
    def speak(self):
        return f'{self.name}: Му!'

Герой и super()

средненовоеавтопроверка

Есть класс Hero(name, hp). Создай класс Wizard(name, hp, mana), который наследует Hero и в своём __init__ вызывает super().__init__(name, hp). Метод cast() тратит 10 маны и возвращает True, а если маны меньше 10 — возвращает False.

Показать ответ (сначала попробуй сам!)
class Hero:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp


class Wizard(Hero):
    def __init__(self, name, hp, mana):
        super().__init__(name, hp)
        self.mana = mana

    def cast(self):
        if self.mana < 10:
            return False
        self.mana -= 10
        return True

Плейлист

сложноновоеавтопроверка

Создай класс Playlist с методом add(song). Сделай так, чтобы работали len(playlist) (метод __len__) и проверка 'Song' in playlist (метод __contains__).

Показать ответ (сначала попробуй сам!)
class Playlist:
    def __init__(self):
        self.songs = []

    def add(self, song):
        self.songs.append(song)

    def __len__(self):
        return len(self.songs)

    def __contains__(self, song):
        return song in self.songs
